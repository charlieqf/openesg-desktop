# OpenESG Review 0.1.0 — Windows x64 团队评审版

用途：评审 OpenCode 内的 ESG 工作台，以及业务页面与原生会话的交互体验。不是生产系统。

## 安装与启动

运行 `OpenESG-Review-0.1.0-Setup-x64.exe`，按向导为当前用户安装。从桌面或开始菜单打开 **OpenESG Review**。不需要安装 Node、Bun、Git 或取得源码。

此内部评审包没有代码签名；请按团队的 Windows 安全策略处理，不能验证来源时不要运行。卸载可使用 Windows“已安装的应用”。它不覆盖普通 OpenCode，也不注册 OpenCode 链接协议，不启用官方自动更新。

## 建议评审路径

1. 打开 ESG 工作台中的演示报告，重点浏览 P02 披露规范、P07 撰写要点、P08 逐要点撰写。
2. 在业务对象上点击“讨论选中对象”，查看业务名称、所属报告和上下文如何进入 OpenCode 原生草稿。
3. 切换底部、右侧、浮动三种会话布局；拖动、缩放应用内浮窗；展开“工作环境”；比较“展开会话”后的原生完整视图。
4. 反馈窗口尺寸、页面/对象名称、操作步骤和截图。浮动面板属于应用内部，不能拖出为第二个 Windows 窗口。

## 本版边界与数据

- 所有 ESG 数值和正文为虚构演示资料，无中央后台、团队同步或真实报告保存。
- 未配置模型，禁用 provider；可评审原生输入和导航，不会产生真实模型回复。不能把这版当作已完成的 Agent 功能。
- 自动恢复报告关联会话尚未实现；“讨论选中对象”显式创建未发送草稿，上下文为点击时的快照。
- 包中不含开发者凭据、日志、数据库和测试会话。首次启动会在 `%APPDATA%\OpenESGReview` 新建独立工作区、会话与日志，仅在本机保存。
- 评审操作可能改变本机演示状态。页面的“重置演示”只重置 ESG 场景，不删除 OpenCode 会话。卸载默认保留本机评审数据。
- 内置 OpenCode V1 本地运行组件及 HTML 资源，无需连接开发服务器。未宣称整机断网或干净虚拟机兼容性已验证。

基于 OpenCode v1.18.30（MIT），保留其原生会话 UI；上游许可见安装目录 `OpenCode-LICENSE.txt`，Electron/Chromium 许可随运行时提供。内部安装包版本独立编号。
